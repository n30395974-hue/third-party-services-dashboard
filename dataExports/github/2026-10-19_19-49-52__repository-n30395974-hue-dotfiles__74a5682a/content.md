# n30395974-hue/dotfiles

My config for zsh, git, tmux, and Neovim.

## Installing
```bash
git clone https://github.com/n30395974-hue/dotfiles ~/.dotfiles
cd ~/.dotfiles && ./install.sh
```

The install script symlinks everything into `$HOME`. Back up your own configs first!
