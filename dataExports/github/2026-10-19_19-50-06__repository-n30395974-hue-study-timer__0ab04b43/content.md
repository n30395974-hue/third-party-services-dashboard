# n30395974-hue/study-timer

A no-frills Pomodoro timer: 25 minutes on, 5 off, one HTML file. Got me through finals last spring.

## Running it
No build step. Open `index.html` in a browser and hit Start.

```bash
# or serve it locally
python -m http.server 8000
```
