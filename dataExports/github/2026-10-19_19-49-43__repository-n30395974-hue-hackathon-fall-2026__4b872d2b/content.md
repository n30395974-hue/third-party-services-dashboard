# SplitIt — HackState Fall 2026

Built in 36 hours at the HackState **hackathon** (Nov 7–9, 2026).

SplitIt is a Slack/Discord bot that tracks who owes what in a group chat. Type
`/split 42.50 pizza @joe @noah` and it does the math.

## Team
- Noah — backend + bot commands
- Joe Smith — frontend dashboard

## Running it
```bash
npm install
cp .env.example .env   # add your bot token
npm run dev
```
