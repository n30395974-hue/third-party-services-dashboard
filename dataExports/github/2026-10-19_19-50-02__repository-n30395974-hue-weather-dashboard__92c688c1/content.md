# n30395974-hue/weather-dashboard

A React + Vite dashboard that shows the 7-day forecast for any city, using the free
[Open-Meteo](https://open-meteo.com/) API.

Made for the CS 340 web dev assignment, then kept tinkering.

## Running it
```bash
npm install
npm run dev
```
